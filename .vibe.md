Allergia — Android-приложение для ведения аллергологического дневника: питание, медикаменты, состояние кожи, бытовая химия и косметика, вейп — всё в одном месте с AI-анализом триггеров.

Стек: Kotlin 2.0, Jetpack Compose + Material 3, Room 2.6 (локальная БД), Hilt (DI), Retrofit + OkHttp, OpenRouter API (Gemini Flash и Gemma 3 4B для vision-задач), DataStore для настроек, Gson для бэкапа.

Сейчас в фокусе: расширение дневника по фидбэку тестировщиков — поля заметок/состава к еде, медикаментам и химии; замена текстового поля областей поражения на структурированный выбор частей тела (ноги/руки/пальцы/лицо/голова/уши) с тремя состояниями каждой; убран раздел симптомов. Параллельно чинили импорт бэкапов из предыдущих версий.

Специфика: zero backend — все данные локально в Room, AI-запросы идут напрямую с устройства в OpenRouter. Бэкап — JSON-экспорт/импорт вручную. Новые поля в Entity всегда String? (nullable) чтобы не ломать импорт старых бэкапов через Gson.
